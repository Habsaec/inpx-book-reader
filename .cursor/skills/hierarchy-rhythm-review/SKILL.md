# Hierarchy and Rhythm Review

Review hierarchy (what gets looked at first) and rhythm (repetition with strategic variation).

## Cursor notes

- Single pass through both hierarchy and rhythm (no subagents).
- For mobile app: check tab bar, hero card, list rows, primary CTA visibility.

## Phase 1: Identify surface

UI files user edited or most recently modified. Note medium (mobile app / dashboard / page).

## Phase 2: Hierarchy review

Per screen/section:
1. Primary / secondary / tertiary — can you tell?
2. **Size** — headings larger than body; primary CTA larger than secondary
3. **Color** — primary in brand color; secondary muted
4. **Weight** — headlines bold, body regular
5. **Position** — primary content in prime real estate
6. **Density** — important content not crammed
7. **5-second test** — main action obvious immediately

## Phase 3: Rhythm review

1. Spacing on 4px/8px scale — flag outliers
2. Type scale — flag arbitrary sizes (17px, 23px)
3. Repetition — cards/lists share structure
4. Strategic variation — occasional pattern break, not chaos
5. Palette discipline — 3–5 colors
6. Section structure — consistent separation
7. Alignment — no off-grid by a few pixels

## Phase 4: Fix and summarize

Snap random values to scale. Strengthen flat hierarchy. Fix reversed hierarchy. Summarize fixes and judgment calls.
