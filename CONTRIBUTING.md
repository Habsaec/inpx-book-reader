# Участие в проекте

Спасибо за интерес к INPX Book Reader! Ошибки и предложения — в [Issues](https://github.com/Habsaec/inpx-book-reader/issues), изменения — через pull request.

Исходный код приложения не распространяется под открытой лицензией (см. [LICENSE](LICENSE)), поэтому вклад принимается только на условиях ниже.

## Права на вклад

Отправляя pull request, патч или другой вклад (код, тексты, графику), вы подтверждаете, что:

1. Вклад создан вами, и вы вправе его передать: он не нарушает чужих прав и обязательств, например перед работодателем.
2. Вы безвозмездно и бессрочно предоставляете владельцу проекта (Александр Шевченко, GitHub: Habsaec) всемирную, безотзывную лицензию на вклад с правом использовать, изменять, распространять, сублицензировать и выпускать его на любых условиях, в том числе коммерческих и закрытых, а также передавать эти права третьим лицам, например при продаже проекта. Там, где это допускает закон, вы передаёте владельцу проекта исключительное право на вклад.
3. Вы не получаете прав на остальной код приложения, кроме своего вклада.

Если вы не согласны с этими условиями, не отправляйте вклад — просто опишите идею в Issue.

## Перед pull request

- Прочитайте [`AGENTS.md`](AGENTS.md): там контракт API с сервером и правила синхронизации.
- Запустите `npm run lint` и `npm test`.
- Держите изменения небольшими и в стиле окружающего кода.
